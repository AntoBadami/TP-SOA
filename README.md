# TP-SOA — Dashboards de Calidad de Aire

Dashboard web que embebe paneles de Grafana con datos de calidad de aire, en split-view (día y semana).

## URLs de Grafana embed

- **Dashboard día:** https://grafana-fabriziobiondi.duckdns.org/d/fagfnz4/aire-detalle-dia
- **Dashboard semana:** https://grafana-fabriziobiondi.duckdns.org/d/fa98846/aire-semana

## Comandos

```bash
npm run dev      # Servidor de desarrollo
npm run build    # Build para producción
npm run preview  # Preview del build
```

## Deploy

Automático via GitHub Actions al pushear a `main`.  
Sitio: https://antobadami.github.io/TP-SOA/
